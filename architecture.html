Sheet 01 — Orientation

The big picture, in five minutes

InsurePortal is read-heavy and form-light: most of the time a user is browsing data that already lives in the API, not typing into forms. Policy management, claim processing, advisor assignment — all of that happens inside LeadCRM itself. This app is a thin, well-organised front end over it. Three ideas explain almost the whole codebase.

01

Three contexts = the entire app state

No Redux, no Zustand. Everything lives in BrandingContext → MemberContext → InsuranceContext, nested in that exact order inside App.tsx because each one depends on the one before it: branding must resolve before login, members must load before insurance data can be filtered by member.

02

apiClient.ts is the only file that touches fetch

It injects the Authorization and X-Org-Code headers automatically and handles every 401 globally. Every other file calls into api.tsx instead — a flat catalogue of named async functions, one per REST operation, grouped by resource.

03

Page files are thin orchestrators

A typical page wraps content in <AppLayout>, reads a filtered list from a context hook, and renders a table, grid or skeleton depending on loading. The real UI always lives one level down, in src/components/{feature}/.

Sheet 06 — Tenancy & Auth

How orgCode gets resolved

One broker's white-label instance is identified by an orgCode string. On every page load, orgUtils.ts walks down this priority chain until something matches.

Auth & header injection

Once resolved, orgCode and the JWT ride along on every request as headers, attached in exactly one place.

Header

Authorization: Bearer …

Read from localStorage["token"] by getAuthHeaders() inside apiClient.ts and attached to every outgoing request automatically.

Header

X-Org-Code: …

Read from localStorage["portal_org_code"], the same way, so the API knows which broker's data to return.

On 401

Hard logout

handleResponse() clears token, user and selectedMemberId, then forces window.location.href = "/". A guard prevents duplicate redirects in the same tick.
